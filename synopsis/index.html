Synopsis

One-Sample Estimators

  • Center⁡(x)\operatorname{Center}(\mathbf{x})Center(x) — robust average
  • CenterBounds⁡(x,misrate)\operatorname{CenterBounds}(\mathbf{x}, \mathrm{misrate})CenterBounds(x,misrate) — confidence interval for center
  • Spread⁡(x)\operatorname{Spread}(\mathbf{x})Spread(x) — robust spread
  • SpreadBounds⁡(x,misrate)\operatorname{SpreadBounds}(\mathbf{x}, \mathrm{misrate})SpreadBounds(x,misrate) — confidence interval for spread
  • Compare1⁡(x,thresholds)\operatorname{Compare1}(\mathbf{x}, \text{thresholds})Compare1(x,thresholds) — confirmatory analysis against practical thresholds

Two-Sample Estimators

  • Shift⁡(x,y)\operatorname{Shift}(\mathbf{x}, \mathbf{y})Shift(x,y) — robust difference
  • ShiftBounds⁡(x,y,misrate)\operatorname{ShiftBounds}(\mathbf{x}, \mathbf{y}, \mathrm{misrate})ShiftBounds(x,y,misrate) — confidence interval for shift
  • Ratio⁡(x,y)\operatorname{Ratio}(\mathbf{x}, \mathbf{y})Ratio(x,y) — robust ratio
  • RatioBounds⁡(x,y,misrate)\operatorname{RatioBounds}(\mathbf{x}, \mathbf{y}, \mathrm{misrate})RatioBounds(x,y,misrate) — confidence interval for ratio
  • Disparity⁡(x,y)\operatorname{Disparity}(\mathbf{x}, \mathbf{y})Disparity(x,y) — robust effect size =Shift⁡/AvgSpread⁡= \operatorname{Shift}\text{/}\operatorname{AvgSpread}=Shift/AvgSpread
  • DisparityBounds⁡(x,y,misrate)\operatorname{DisparityBounds}(\mathbf{x}, \mathbf{y}, \mathrm{misrate})DisparityBounds(x,y,misrate) — confidence interval for disparity
  • Compare2⁡(x,y,thresholds)\operatorname{Compare2}(\mathbf{x}, \mathbf{y}, \text{thresholds})Compare2(x,y,thresholds) — confirmatory analysis against practical thresholds

Randomization

  • r←Rng⁡(s)r \leftarrow \operatorname{Rng}(s)r←Rng(s) — random number generator with seed sss
  • r.UniformFloat⁡()r.\operatorname{UniformFloat}()r.UniformFloat() — uniform random value in [0,1)[0, 1)[0,1)
  • r.UniformInt⁡(a,b)r.\operatorname{UniformInt}(a, b)r.UniformInt(a,b) — uniform random integer in [a,b)[a, b)[a,b)
  • r.Sample⁡(x,k)r.\operatorname{Sample}(\mathbf{x}, k)r.Sample(x,k) — select kkk elements without replacement
  • r.Resample⁡(x,k)r.\operatorname{Resample}(\mathbf{x}, k)r.Resample(x,k) — select kkk elements with replacement
  • r.Shuffle⁡(x)r.\operatorname{Shuffle}(\mathbf{x})r.Shuffle(x) — uniformly random permutation
